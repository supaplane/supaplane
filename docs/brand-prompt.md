# Brand Prompt

The canonical brand description for Supaplane. Use this verbatim, or paraphrase, when prompting image generators, onboarding new collaborators, or pitching the project in one paragraph.

## Short form (paste-ready)

> Supaplane is a local-first workbench for coding agents. The brand is a single cream origami paper plane. The plane is the chassis. Identity, whether an agent harness, a human avatar, or a custom SOUL mascot, rides on top of the plane as a sticker or badge. The plane itself never changes color. Sticker density, finish, and placement express personality. Formations of identical planes with different riders express the multiplayer metaphor. The feel is handcrafted, folded, local, deliberate. Not metallic. Not cloud. Not another purple AI dashboard. Warm paper neutrals on charcoal, with amber reserved as a functional UI accent.

## Long form

Supaplane is a multi-surface workbench that imports your existing coding harnesses (Claude Code, Codex, OpenCode, Cursor, anything ACP) and flies them in parallel from desktop, web, or phone. One supervised daemon on the user's machine owns agent lifecycle, worktrees, and remote access. The renderers are thin clients over that daemon.

The visual identity mirrors the product's posture:

- **Local-first.** Handcrafted paper, folded by hand, not stamped in a cloud foundry.
- **Multi-harness.** Same plane, many riders. Never recolour the chassis to mean "this is Claude" or "this is Codex". The badge on top says that.
- **Multiplayer.** The default surface is a sky of paper planes in formation, not a chat pane. You read who's running by reading the rider, the posture, and the trail, not by parsing tabs.
- **Open, not corporate.** Open source MIT. The plane and the sticker sheet are a metaphor for participatory culture: anyone can paste a sticker on their plane.

The Fold system is paper + charcoal with a single amber accent for UI signal. Marks fall into four roles: structure (`#07` mono), product (`#10` flat app icon), soul (`#01` photoreal cream), gallery (`#05` white-on-black premium stills). Stickers come in two finishes, matte (default harness badges) and foil (premium, favourite agents, SOUL rare drops). Crashes are expressed by posture (crumpled wing, dipped tip), never by repainting the plane.
